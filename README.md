# Flowdesk Landing Page

A responsive landing page built from scratch with HTML, CSS and vanilla JavaScript.

## Overview

This project was created to practise structuring and styling a complete web page, while adapting the interface to different screen sizes.

## Features

* Responsive desktop and mobile layouts
* Mobile navigation menu
* Interactive elements with vanilla JavaScript
* Custom hover states and visual styling
* Clear and structured page sections

## Technologies

* HTML5
* CSS3
* JavaScript

## Run locally

Clone the repository and open `index.html` in your browser.

```bash
git clone https://github.com/wilmetjph/flowdesk.git
cd flowdesk
open index.html
```
