# Flowdesk

A responsive pricing page built with HTML, CSS and vanilla JavaScript.

**[Live Demo](https://wilmetjph.github.io/flowdesk/)**

## About the project

Flowdesk is a front-end development project featuring a responsive pricing page, interactive FAQ section and contact form interface.

The project was developed to practise responsive layouts, CSS styling and DOM manipulation using vanilla JavaScript.

## Technologies

- **HTML5** — Page structure and semantic elements
- **CSS3** — Responsive design and layout
- **JavaScript** — DOM manipulation and user interactions

## Project status

Completed as a front-end learning project. Further improvements may be added over time.
